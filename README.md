# Гонка для двоих ♥

Мультяшная 2.5D-гонка в браузере для двух игроков онлайн. Без сервера и без установки: браузеры соединяются напрямую (WebRTC через PeerJS).

## Как играть

1. Открой игру, введи имя, выбери гонщика и нажми **«Создать комнату»**.
2. Скопируй ссылку и отправь её второму игроку.
3. Второй игрок открывает ссылку и жмёт **«Поехали!»**, после этого любой из вас нажимает **«Старт!»**.

Управление: стрелки или WASD (на телефоне есть кнопки на экране). Сердечки на дороге дают ускорение, а в конусы и деревья лучше не врезаться. Клавиши 1–4 отправляют смайлики.

## Запуск на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
Через минуту игра будет доступна по адресу `https://<user>.github.io/racing/`.

## Локально

```
python3 -m http.server 8000
```
Потом открой http://localhost:8000

## Своё

Надписи на щитах вдоль трассы меняются в `js/config.js`.

## Структура

- `js/sprites.js`: вся графика (персонажи сзади и спереди в 3/4, карты, декорации), рисуется процедурно
- `js/road.js`: трасса из сегментов (повороты, холмы, расстановка декораций)
- `js/game.js`: 2.5D-рендер, физика, интерфейс, синхронизация
- `js/net.js`: соединение двух игроков
